เลือกได้หลายใบพร้อมกัน (หลายคน) กดชื่อไฟล์ด้านล่างเพื่อดูตัวอย่างของแต่ละใบ

กำลังอ่านไฟล์…
รันวันที่ – 📁 บันทึกไปที่ — ดาวน์โหลดปกติ —
ยังไม่มีไฟล์ วางไฟล์รายการหนังและใบเช็ครูปด้านบน ระบบจะแสดงรายการของแต่ละจอตรงนี้ เทียบกับของเดิมในใบเช็ค (ถ้ามี)
กติกาการจัดรายการ และชื่อที่ไม่ต้องใส่
  • ใช้เฉพาะรายการที่ออนแอร์ (ส่วนบนของไฟล์) ไม่เอาส่วน "ถอด" / "รายการปลด"
  • ชื่อซ้ำในจอเดียวกันใส่ครั้งเดียว และเรียงตามตัวอักษร (ไม่สนตัวพิมพ์เล็กใหญ่)
  • BKJ1 / BKJ2: ตัด BKJ_ / BKJ1_ / BKJ2_ หน้าชื่อออก, ไม่เอา Traffic, ดูช่อง "เฉพาะ" และ "ยกเว้น" ตามเลขจอ
  • ใบเช็ค ID-25 ใช้บล็อก "THE CITY" ในไฟล์ CITY
  • วันที่ 1 ไม่ใส่ "ออก" (รายการแอดออกเริ่มใส่วันที่ 2)
  • ถ้ารายการยาวเกินช่องว่างก่อนแถววันที่ 2 ระบบจะแทรกแถวเพิ่มให้
  • ใส่ไฟล์รายการหนังได้ทีละวันหรือหลายวันพร้อมกัน (ระบบรันเรียงทีละวันให้) + ใบเช็คล่าสุด ถ้าเป็นวันที่ 1 ใส่ทั้งหมด ถ้าเป็นวันถัดไป ระบบต่อท้ายใต้รายการเดิมเป็นวันใหม่
  • วันถัดไปใส่เฉพาะ ขึ้นใหม่, ขึ้นใหม่ไฟล์เดิม, ต่อสัญญา + ขึ้นใหม่ไฟล์เดิม, ไฮไลท์เหลือง (Metro: เหลืองและสีครีม ตามแท็บของวันที่นั้น) และไม่ใส่ซ้ำกับที่มีในใบเช็คแล้วในช่วงวันที่ 1–15 (16–สิ้นเดือนนับใหม่ ซ้ำกับรอบ 1–15 ได้) · แถบวันที่ 1–15 สีฟ้า, 16–สิ้นเดือน สีม่วง
  • รันวันที่ย้อนหลังที่ใบเช็คยังไม่มีได้ ระบบแทรกก่อนวันถัดไปให้ (ไม่ใส่ "ออก" ย้อนหลัง)
  • หนังในใบเช็คที่ไม่อยู่ในไฟล์ของวันนี้แล้ว ใส่ "ออก N" ข้างชื่อให้ (ตัวแดง ชิดขวา)
  • หนังที่ขึ้นต้นด้วย PB_ / MD_ / PR_ ใส่ # ข้างหน้า (#PB_ …) ไฮไลท์เหลือง และอยู่บนสุดก่อนรายการ A B C …

ชื่อที่ไม่ต้องใส่ (หนึ่งบรรทัดต่อหนึ่งรูปแบบ, ใช้ regex)

ขั้นที่ 1 · ไฟล์รายการปลด

ไฟล์รายการหนัง PBTV BKK - CITY · BKJ1 · BKJ2 · Metro LED ทั้งเดือน

ลากทั้งโฟลเดอร์ (เช่น รายการหนังถอดด่วน) มาวางได้เลย ระบบอ่านส่วน "รายการปลด" / "รายการถอดสปอต" ของทุกวัน · วันที่ออก = วันที่ในชื่อไฟล์ (Metro ใช้วันที่ของแต่ละแท็บ)

ลากไฟล์ หรือโฟลเดอร์ มาวางที่นี่หรือกดเพื่อเลือกทั้งโฟลเดอร์

กติกาคะแนนฟรี
  • อ่านแท็บ "สูตร OFF (รายวัน)" (รายการปลดของวันนั้น) ถ้าไม่มี ใช้หัวข้อ "รายการปลด" ในแท็บรายการหนัง
  • แยกแพ็คตามคอลัมน์ Type: PBTV40Blue → 40Blue · PBTV40Red → 40Red · PBTV80Blue → 80Blue · PBTV80Red → 80Red · CITY TV → CITY · Customization → Customize (ประเภทอื่นไม่นับ)
  • BKJ1 / BKJ2 (ไฟล์ "รายการหนังสื่อ BKJ1_รอบ_…" / "BKJ2_รอบ_…" รายวัน): ใช้หัวข้อ "รายการปลด" ทั้งหมด → เติมในชีท BANGKOK_JAM1 / BANGKOK_JAM2_A, _B · ชื่อในใบเช็คไม่มี BKJ_ นำหน้า ระบบตัดให้เอง
  • BKJ1 หมายเหตุ "มีไปชดเชยที่ BKJ2-35" → เติมใน BKJ1 ทุกจอ และเติมจอ 35 ในชีท BANGKOK_JAM2 ด้วย ("ไม่มีไปชดเชย" / "ไม่รับชดเชย" = ไม่เติม BKJ2-35) · BKJ2 Type "BKJ2-35_…" = เติมเฉพาะจอ 35 · "ไม่ออน BKJ2-35" / ยกเว้น BKJ2-35 = เติมทุกจอยกเว้น 35
  • รายการปลดของ วันที่ 1 (เช่น แท็บ 1 Oct ของ Metro) ไม่นับ — เริ่มนับวันที่ 2 ถึงสิ้นเดือน
  • Metro LED (ไฟล์ "7-Eleven Metro LED" ไฟล์ล่าสุดไฟล์เดียว มีแท็บรายวัน): ใช้หัวข้อ "รายการถอดสปอต" ของแต่ละแท็บ · วันที่ออน = การออกอากาศ Start · วันที่ออก = วันที่ของแท็บ → เติมในชีท LEDMETRO
  • Customization ดูช่อง "หมายเหตุ" ก่อน: เติมเฉพาะจอที่เขียนไว้ (DGT…, DGT-A…, ID-…, ชื่อจอ) โดยหาจอนั้นในทุกชีทของใบเช็ค · "ถอดระหว่างวัน วันที่ 1/10/26" = ใช้เป็นวันที่ออก · "ออนแอร์ระหว่างวัน วันที่ 12/10/26" = ใช้เป็นวันที่ออน · ข้อความหลัง // แสดงให้ดูเฉย ๆ
  • วันที่ออน = เริ่ม On-Air (ถ้าออนก่อนต้นเดือน ใช้วันที่ 1) · วันที่ออก = วันที่ของไฟล์ · นับวันรวมหัวท้าย (1/10 → 3/10 = 3 วัน)
  • เก็บเฉพาะรายการที่ไม่เกิน 6 วัน (แก้ได้ด้านบน) · 7 วันขึ้นไปตัดทิ้ง
  • ชื่อเดียวกัน วันออนเดียวกัน อยู่ในรายการปลดหลายวัน → ใช้วันแรกที่ปลด
  • เติมเลข วันสิ้นเดือน (30 หรือ 31) ลงช่องคะแนนของ ทุกจอ ที่มีชื่อหนังนั้นในชีทแพ็คเดียวกัน เฉพาะช่องที่ยังว่าง (ช่องที่มีคะแนนแล้วข้าม)
  • ถ้าชื่อหนังมีหลายแถว (รอบ 1–15 และ 16–31) เติมแถวของรอบที่ใกล้วันที่ออกที่สุด
  • ชื่อที่ไม่ต้องนับ ใช้รายการเดียวกับหน้า A (FastAd, Programmatic ฯลฯ)
